## <span style="color:#8B4513">⚔️ What is SRLU?</span>

**<span style="color:#8B4513">S</span><span style="color:#8B4513">R</span><span style="color:#8B4513">L</span><span style="color:#8B4513">U</span> <span style="color:#fff">|</span> <span style="color:#8B4513">Skyrim</span> <span style="color:#fff">Level-</span><span style="color:#8B4513">U</span><span style="color:#fff">p!</span>** <span style="color:#e67e23">brings the iconic</span> <span style="color:#8B4513">Skyrim</span> <span style="color:#e67e23">level-up sound to</span> <span style="color:#06c">World of Warcraft</span><span style="color:#e67e23">! Experience that epic, triumphant chime every time you level up — no more bland default sounds. Whether you're a veteran Dragonborn or new to Skyrim, this addon brings that satisfying level-up feeling to your WoW adventures.</span>

### <span style="color:#8B4513">🔥 Why Choose SRLU?</span>
- **<span style="color:#2dc26b">🎵 Epic Sound:</span>** <span style="color:#e67e23">The authentic Skyrim level-up chime in high, medium, and low quality</span>
- **<span style="color:#8B4513">🌍 Multi-Interface:</span>** <span style="color:#e67e23">One TOC declares the Classic Era, Cataclysm Classic, Mists Classic, and Retail interface values listed below</span>
- **<span style="color:#b96ad9">🌐 Multi-Language:</span>** <span style="color:#e67e23">Supports 5 languages with automatic detection</span>
- **<span style="color:#4ecdc4">🔇 Smart Muting:</span>** <span style="color:#e67e23">Auto-mutes WoW's default level-up sound</span>
- **<span style="color:#ff6b6b">💬 Community:</span>** <span style="color:#e67e23">Repository issues and Discord links are available below</span>

## <span style="color:#8B4513">✨ Features</span>

<div align="center">

| Feature | Description |
|---------|-------------|
| 🎵 **Epic Sound** | Iconic Skyrim level-up chime plays on every level gained |
| 🎚️ **Quality Options** | High, Medium, and Low quality sound variants |
| 🔧 **Easy Commands** | Simple `/srlu` slash command interface |
| 💾 **Persistent Settings** | Settings saved automatically between sessions |
| 🌍 **Multi-Language** | 5 languages supported with automatic detection |
| 🔇 **Smart Muting** | Auto-mutes WoW's default level-up sound |

| 🛡️ **Error Protected** | Slash-command dispatch is wrapped in `pcall` |
| 🎮 **Multi-Interface** | Uses the single TOC and interface list documented below |

</div>

<a id="command-reference"></a>
## <span style="color:#8B4513">📋 Command Reference</span>

<span style="color:#e67e23">Use</span> <span style="color:#2dc26b">`/srlu`</span> <span style="color:#e67e23">followed by</span><span style="color:#3598db">:</span>

<div align="center">

| Command | Description |
|---------|-------------|
| `/srlu help` | Show all available commands |
| `/srlu test` | Play test sound |
| `/srlu enable` | Enable the addon |
| `/srlu disable` | Disable the addon |
| `/srlu high` | Use high quality sound |
| `/srlu med` | Use medium quality sound (default) |
| `/srlu low` | Use low quality sound |

</div>

<a id="compatibility"></a>
## <span style="color:#8B4513">📋 Compatibility</span>

<div align="center">

| Client family | Interface metadata | TOC file |
|-------------|-----------|----------|
| **Retail** | `110207`, `120000`, `120001`, `120005` | `SkyrimLevelUp.toc` |
| **Mists of Pandaria Classic** | `50503` | `SkyrimLevelUp.toc` |
| **Cataclysm Classic** | `40402` | `SkyrimLevelUp.toc` |
| **Classic Era** | `11508` | `SkyrimLevelUp.toc` |

</div>

The TOC currently reports addon version `3.0.1`, declares `SRLUSettings`, and requires `RGX-Framework`. These are metadata facts, not a promise of support for client interfaces not listed above. Install the framework as a separate enabled addon before loading SRLU.

<a id="installation"></a>
## <span style="color:#8B4513">📥 Installation</span>

1. **<span style="color:#2dc26b">Download</span>** <span style="color:#e67e23">from your preferred platform</span><span style="color:#3598db">:</span>
   - [<span style="color:#ff6b6b">CurseForge</span>](https://www.curseforge.com/wow/addons/srlu)
   - [<span style="color:#b96ad9">Wago.io</span>](https://addons.wago.io/addons/srlu)
   - [<span style="color:#24292e">GitHub</span>](https://github.com/DonnieDice/SRLU/releases)

2. **<span style="color:#4ecdc4">Extract</span>** <span style="color:#e67e23">to your</span> <span style="color:#06c">WoW</span> <span style="color:#e67e23">AddOns directory</span><span style="color:#3598db">:</span>
   - <span style="color:#e67e23">**Retail**: `World of Warcraft/_retail_/Interface/AddOns`</span>
   - <span style="color:#e67e23">**Classic**: `World of Warcraft/_classic_/Interface/AddOns`</span>
   - <span style="color:#e67e23">**Classic Era**: `World of Warcraft/_classic_era_/Interface/AddOns`</span>

3. **<span style="color:#b96ad9">Install the dependency</span>** <span style="color:#e67e23">so `Interface/AddOns/RGX-Framework/RGX-Framework.toc` is present.</span>

4. **<span style="color:#b96ad9">Restart</span>** <span style="color:#06c">WoW</span> <span style="color:#e67e23">and enable both `RGX-Framework` and SRLU in the AddOns menu.</span>

## <span style="color:#8B4513">🔧 Troubleshooting</span>

**<span style="color:#ff6b6b">No sound playing?</span>**
- <span style="color:#e67e23">Run</span> `/srlu test` <span style="color:#e67e23">to verify the addon is active and sound is working</span>
- <span style="color:#e67e23">Check that your in-game Master volume is not muted</span>
- <span style="color:#e67e23">Confirm the addon is enabled with</span> `/srlu enable`
- <span style="color:#e67e23">Confirm `RGX-Framework` is installed and enabled; SRLU cannot load without it</span>

**<span style="color:#ff6b6b">Wrong language?</span>**
- <span style="color:#e67e23">The addon auto-detects your WoW client language. If it's incorrect, check your WoW language settings</span>

**<span style="color:#ff6b6b">Settings not saving?</span>**
- <span style="color:#e67e23">Ensure WoW has write permissions to its SavedVariables folder</span>
- <span style="color:#e67e23">`/reload` can sometimes resolve settings persistence issues</span>

**<span style="color:#ff6b6b">Still having trouble?</span>**
- <span style="color:#e67e23">Use the</span> [<span style="color:#7289da">Discord</span>](https://discord.gg/N7kdKAHVVF) <span style="color:#e67e23">community for discussion</span>
- <span style="color:#e67e23">Open a</span> [<span style="color:#ff6b6b">GitHub Issue</span>](https://github.com/DonnieDice/SRLU/issues)
